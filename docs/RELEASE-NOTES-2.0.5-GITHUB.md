# HongMix 2.0.5

## 한국어

- 여러 카메라를 한 창에서 제어하는 **PTZ Control**, VISCA over IP/TCP/UDP 및 NDI PTZ
- Finder 파일 드롭과 **Photos · PDF Slides · Virtual Set** 입력
- 학습 모드·장치 템플릿·LED 탤리를 갖춘 **MIDI 컨트롤**
- 강제 종료 복구형 녹화, 백업/이어쓰기 디스크, 남은 시간 경고 및 **송출 모니터**
- 장시간 방송용 A/V 시계 보정, 장치 자동 재연결, 딜레이 유지, 끊김 없는 루프와 안전한 파일 분할

M1 Max에서 녹화 및 SRT 송출을 각각 60분 검증했습니다. 실제 PTZ 카메라, DeckLink, MIDI 컨트롤러와 USB 장치 재연결은 아직 실제 장비 검증 전입니다.

전체 내용: [한국어 릴리스 노트](https://github.com/HongMix/HongMix/blob/main/docs/RELEASE-NOTES-2.0.5.ko.md)

## English

- Multi-camera **PTZ Control** with VISCA over IP/TCP/UDP and NDI PTZ
- Finder file drop plus **Photos, PDF Slides and Virtual Set** inputs
- **MIDI control** with learn mode, device templates and LED tally
- Crash-resilient recording, backup/rollover disks, time-left warnings and a **stream monitor**
- Long-show A/V clock compensation, device reconnection, retained delay, gapless loops and safe file splitting

Recording and SRT streaming were each verified for 60 minutes on an M1 Max. Real PTZ cameras, DeckLink, MIDI controllers and USB device replugging have not yet been hardware-tested.

Full details: [English release notes](https://github.com/HongMix/HongMix/blob/main/docs/RELEASE-NOTES-2.0.5.md)
