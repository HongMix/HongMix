# HongMix 2.2.5 (빌드 134)

HongMix 2.2.5는 웹 리모트를 화면 크기에 맞춰 바뀌는 브라우저 스위처로 확장하고, 그림이 포함된 한국어·영어 전체 사용 설명서를 추가했습니다. 배포하지 않은 2.2.4의 탈리와 원격 제어 개선도 포함합니다.

## 브라우저 안의 스위처

- 웹 리모트가 앱과 같은 Preview·전환·Program·입력 타일·Audio Mixer·오버레이 1–8·T-Bar·FTB 흐름을 제공합니다.
- 입력 타일을 누르면 Preview, 타일의 **Cut**은 바로 Program, **1–8**은 그 입력을 오버레이로 올리고 내립니다. 미디어 타일에는 처음부터·재생/일시정지가 있고, Program에는 송출 중 미디어의 재생·탐색 막대가 있습니다.
- 녹화·송출·External은 항상 확인창을 띄웁니다. 길게 누른 뒤 송출이 꺼졌다 다시 켜지던 문제도 해결했습니다.
- 페이지에서 한국어·영어를 바꾸고 **?**로 사용법을 확인합니다.

## 노트북·아이패드·휴대폰 배치

- 데스크톱과 아이패드 가로는 사이드 패널이 있는 전체 스위처 배치를 사용합니다.
- 아이패드 세로는 두 모니터·전환 막대·4열 입력 타일·아래쪽 탭으로 바뀝니다.
- 휴대폰은 작은 모니터·2열 입력 타일과 스위처·오디오·타이틀·더보기 탭을 사용합니다. 화면을 돌리면 다시 배치합니다.
- 카메라 탈리는 보기 전용이며 비밀번호 없이 열리고, 기기에 화면을 계속 켜 달라고 요청합니다.

## 그림으로 보는 전체 사용 설명서

- [한국어 설명서](manual/HongMix-Manual.ko.md)와 [English manual](manual/HongMix-Manual.en.md)은 각각 16장과 해당 언어 캡처 14장을 포함합니다.
- 설치, 메인 화면, 입력, 전환, 오버레이, 위치·레이어, 오디오, 타이틀, 출력, 리플레이, 자막, 방송 안전, 웹 리모트·탈리, API, 설정, 문제 해결을 다룹니다.
- 공개 캡처에는 생성한 테스트 패턴만 사용했고, 기기 이름과 내부·공인 IP는 문서용 예시 값으로 바꿨습니다.

## 검증

- 가상 스위처 화면 검사: 데스크톱 65/65, 아이패드 65/65, 휴대폰 66/66.
- 실제 앱 연동 검사: 47/47, 드롭 프레임 0.
- 번역·코어 테스트·체크섬·DMG·애드혹 서명 검증을 통과했습니다.
- 시험 중 휴대폰 390px 화면이 515px로 넓어지던 하단 막대 문제를 찾아 수정했습니다.

## 알려진 제한

- 실제 휴대폰·아이패드 기기 시험은 남아 있습니다. 반응형 배치는 브라우저에서 각 기기의 실제 화면 크기로 검증했습니다.
- 페이지는 데스크톱에서 0.4초, 작은 화면에서 0.7초마다 상태를 확인합니다. 이전 부하 시험에서 바쁜 클라이언트 7개는 CPU 약 10%를 사용했습니다.
- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
