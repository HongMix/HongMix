# HongMix 2.2.0 (빌드 121)

HongMix 2.2.0에는 2.1.7~2.1.8의 위치·레이어·AI 화질 올리기·프리셋·다중 레이어 편집 기능과 macOS 메뉴 막대에서 단축어 아이콘이 반복해서 나타나던 문제의 수정이 모두 들어 있습니다.

## 메뉴 막대와 AI 상태 표시

- 방해 금지 단축어를 30초마다 실행하지 않습니다. 앱 시작·상단 버튼 사용·다른 앱에서 HongMix로 돌아올 때만 상태를 확인합니다.
- 약 27분 동안 프로세스를 감시한 결과 앱 시작과 종료 때만 실행됐으며 15분 재생 시험 중에는 한 번도 실행되지 않았습니다.
- AI 화질 올리기는 입력이 송출에 없을 때 `대기`로 표시하고 Preview·Program·송출 중 레이어에 올라오면 실행 상태로 바뀝니다.

## 포함된 편집 기능

- Program과 같은 미리보기에서 숫자값·자르기 손잡이·회전·불투명도·잠금·되돌리기·화면 밖 여백을 사용해 위치와 레이어를 직접 편집합니다.
- 입력과 프로젝트를 넘나들며 다시 쓰는 레이어 위치 프리셋을 저장합니다.
- Shift-클릭 또는 Command-A로 여러 레이어를 선택해 함께 이동·정렬·간격·크기를 조정하며 다른 레이어의 가장자리와 가운데에 스냅합니다.
- 예전 프로젝트는 열 때 자동 변환해 이전 자르기의 실제 화면 모습을 유지합니다.

## 호환성과 안정성

- 합성 테스트 파일 22개를 모두 열고 재생했습니다. H.264, HEVC 4K/Main10, ProRes 422/4444 알파, VP9, AV1, MPEG-2, 세로·인터레이스 영상, 모노·44.1kHz·PCM·AC-3 5.1·오디오 전용, PNG·JPG·GIF·알파 이미지를 포함합니다.
- 빌드 120에서 입력 22개를 연 15분 시험 동안 프레임 빠짐 0, 오류 0, 재시작 0이었고 메모리는 1,055~1,120MB로 일정했습니다. 가장 느린 렌더 프레임은 33ms 프레임 간격 안의 9.1ms였습니다.
- AI 상태 표시를 고친 빌드 121의 5분 재시험도 프레임 빠짐과 오류가 0이었고 메모리는 1,070~1,149MB로 일정했습니다.
- 2.1.6 형식으로 바꾼 프로젝트도 입력 22개와 기존 자르기 화면을 유지하며 다시 열렸습니다.
- 코어 테스트·번역·체크섬·DMG·애드혹 앱 서명 검증을 통과했습니다.

## 알려진 제한

- 실제 Shift-클릭·그룹 드래그·Command-A·드래그 스냅·회전 자르기·화살표 키·Command-Z·숫자칸·프리셋 이름 창은 더 많은 직접 조작 검증이 필요합니다.
- 일반 데스크톱 사용 중 메뉴 막대 아이콘이 보이지 않는지는 사용자가 눈으로 한 번 확인해야 합니다.
- 회전 레이어의 정렬과 테두리는 회전 전 상자를 기준으로 합니다. 프리셋은 프로젝트 파일이 아닌 앱 전체에 저장됩니다. 되돌리기 기록은 현재 앱 실행 중에만 유지됩니다.
- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
