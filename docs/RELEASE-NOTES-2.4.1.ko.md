# HongMix 2.4.1 (빌드 202)

HongMix 2.4.1은 2.4.0에서 생긴 AUTO 트랜지션 중 Preview/Program 모니터 끊김을 고칩니다.

## 트랜지션이 다시 부드럽게

- 운영자 프로젝트에서 Fade·Merge·Wipe·Fly 중 스위처 모니터가 53~60fps를 유지했습니다. 2.4.0에서는 25~38fps였습니다.
- 실제 Program 송출 프레임은 빠지지 않았으며, 스위처 모니터와 조작 화면의 문제였습니다.
- AUTO 상태와 T바는 이제 스위처 엔진을 보는 모든 화면 대신 트랜지션 조작부만 갱신합니다.

## 창 미리 만들기 제거

2.4.0에서 추가한 숨은 창 미리 만들기는 해당 창을 계속 메모리에 남겨 트랜지션 때 화면 계산을 무겁게 했습니다. 방송 중 트랜지션을 우선해 제거했습니다. 보조 창을 처음 열 때는 다시 2.3.10 수준인 약 0.1~0.4초가 걸립니다.

## 검증과 남은 한계

- AUTO 트랜지션 1~4를 각각 5번 실행해 스위처 모니터 53~60fps, Program 드랍 0을 확인했습니다.
- 실행·20회 페이드·10회 컷 회귀 검사에서 드랍 0/0/0, 반복 실행 5회에서 충돌 0, 시작 소리 0회였습니다.
- 이번 시험에서는 리플레이 녹화를 시작하지 않았습니다. 2.4.0에서 검증한 리플레이 코드와 보호 기능은 변경하지 않았습니다.
- 제보받은 오디오 믹서 복귀 문제는 빌드 198과 시험 빌드 200에서 재현되지 않았습니다. 가장 유력한 원인이던 창 미리 만들기는 제거했습니다. 다시 발생하면 닫기·열기 순서를 알려 주세요.
- 번역·핵심·MultiView 검사를 통과했습니다. 빌드 202 DMG는 유효성 및 임시 서명 검사를 통과했습니다.
- 트랜지션이 끝나며 Program/Preview가 바뀌는 순간과 다른 엔진 전체 변경은 화면을 약 0.2~0.3초 멈추게 할 수 있습니다. 완전한 해결에는 예정된 Swift Observation 전환이 필요합니다.
- 공개 앱은 임시 서명이며 Apple 공증 전이고, PKG에는 설치 패키지 서명이 없습니다.
