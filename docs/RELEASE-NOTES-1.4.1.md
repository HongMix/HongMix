# HongMix 1.4.1

## Appearance and workflow

- The original HongMix skin remains the default.
- `Graphite Broadcast` can be selected in Settings > General > Appearance.
- Graphite changes only control panels and the top/bottom tool areas. Preview, Program, video, and audio-meter colours remain unchanged.
- Statistics & Monitoring opens as an independent window that can move to another display or macOS desktop.

## Display output

- The former Fullscreen control is now organised as `Display`.
- `Output Window` supports resizing, movement across displays and desktops, and native macOS fullscreen using the green window button.
- `Display Fullscreen` fills the selected monitor with the broadcast view.
- Sources include Program, Clean Program, Preview, Multiview, and individual inputs.
- Output Window provides Always on Top and Lock 16:9 options.
- The selected mode, display, and window options persist across launches.

## Language and diagnostics

- Korean and English UI modes can be selected separately in Settings.
- The monitoring window provides Overview, Inputs & Devices, Network, Outputs, and Diagnostics tabs.
- Live Program video and audio monitoring remains available in the independent window.

## Validation notes

- DeckLink Fill/Key and SDI I/O code is included, but each card and Desktop Video configuration still requires hardware validation.
- This package is ad-hoc signed. Apple Developer ID signing and notarization are required for warning-free distribution to other Macs.
