HongMix 2.2.0 사용 설명서 (한국어)
================================================================
맥(Apple Silicon)용 라이브 프로덕션 스위처. vMix와 같은 화면 구성·단축키·API로 동작합니다.
만든 사람: 홍승훈 (Hong Seunghoon) · 2026-10-28 · 대한민국


1. 설치
----------------------------------------------------------------
필요 사양: Apple Silicon 맥(M1 이후 전 모델), macOS 14 이상.
SDK·라이브러리(FFmpeg, SRT, NDI 런타임, Chromium 웹 엔진)는 모두 앱 안에 들어 있어 따로 설치할 것이 없습니다.

[방법 A — 권장] HongMix-2.2.0.pkg 더블클릭
  1) 처음 열 때 "확인되지 않은 개발자" 경고가 뜨면: 파일을 우클릭 → [열기] → [열기].
     (또는 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 [그래도 열기])
  2) 설치 마법사에서 [계속] → [설치]. 응용 프로그램 폴더에 HongMix가 설치됩니다.
  3) 첫 실행 때 경고가 뜨면 응용 프로그램 폴더의 HongMix를 우클릭 → [열기] → [열기] (한 번만).
     (아직 Apple 공증을 받지 않은 앱이라 macOS가 한 번 확인합니다.)

[방법 B] HongMix-2.2.0.dmg 열기 → HongMix를 Applications 폴더로 드래그
  - 처음 실행 때 경고가 뜨면 앱을 우클릭 → [열기] (한 번만).

처음 실행하면 macOS가 권한을 묻습니다.
  - 카메라 / 마이크: 카메라·마이크 입력을 쓸 때 [허용]
  - 화면 기록: 화면/창 캡처 입력을 쓸 때만 필요 (시스템 설정 → 개인정보 보호 및 보안 → 화면 및 시스템 오디오 녹음)
  - 로컬 네트워크: NDI·SRT 장비를 찾을 때 [허용]

2.2.0 새 기능
  - 방해 금지 단축어를 30초마다 실행하지 않습니다. 앱 시작·상단 버튼 사용·HongMix로 돌아올 때만
    상태를 확인해 메뉴 막대 단축어 아이콘이 반복해서 나타나는 문제를 해결했습니다.
  - AI 화질 올리기는 입력이 Program·Preview·송출 중 레이어에 올라가기 전까지 대기 상태를 표시합니다.
  - 2.1.7~2.1.8의 위치·레이어·AI 화질 올리기·프리셋·다중 레이어 편집 기능을 모두 포함합니다.
  - 레이어 위치·크기·자르기·회전·불투명도·테두리·채우기/맞추기를 프리셋으로 저장해
    어느 입력과 프로젝트에서든 다시 적용합니다. 소스 입력 자체는 프리셋에 저장하지 않습니다.
  - Shift-클릭 또는 Command-A로 레이어를 함께 선택해 이동·정렬·간격·크기를 한꺼번에 맞춥니다.
  - 레이어를 움직일 때 다른 레이어의 가장자리와 가운데에도 스냅됩니다.
  - 회전한 레이어를 자를 때도 회전하지 않은 레이어처럼 그 상자 변이 함께 움직입니다.
  - LayerPreset과 LayerPresetSave로 Companion·Stream Deck에서 프리셋을 제어합니다.
  - 위치·레이어의 모든 값에 숫자칸과 −/+를 넣었습니다. 화살표 키는 한 단계, Shift는 열 단계입니다.
  - 회색 여백에서 화면 밖 상자와 손잡이를 계속 잡을 수 있습니다. 레이어에는 화면에 맞추기·가운데·
    원래 비율·전체 화면·위치 복사/붙여넣기·잠금·불투명도·회전을 넣었습니다.
  - 레이어 자르기가 상자를 채웁니다. 투명 배경만 잘라내기를 쓸 수 없는 소스는 이유를 바로 표시합니다.
    이전 버전 프로젝트는 열 때 자동 변환해 기존 모습을 유지합니다.
  - 지원되는 macOS에서 선택형 AI 화질 올리기로 저해상도 송출 소스를 확대합니다.
  - 레이어 합성 캐시로 레이어가 많은 장면의 성능을 개선했습니다.
  - 원격 제어는 기본으로 꺼집니다. Companion·Stream Deck·웹 리모트 사용자는 업데이트 후
    설정 > 네트워크에서 한 번 켜 주세요.
  - 위치·레이어 화면에서 안쪽 끌기 이동, 노란 모서리 크기, 주황 손잡이 자르기,
    Option-끌기로 보이는 부분 이동을 바로 조작합니다. 값은 출력 픽셀로 표시합니다.
  - Program과 같은 실시간 미리보기를 오른쪽에 고정하고 왼쪽 설정만 스크롤합니다.
  - 투명 여백 자동 자르기로 자막·PNG 레이어의 빈 알파 영역을 제거한 뒤 채우기를 적용합니다.
  - 가상 입력이 송출될 때 원본 오디오가 AUTO이면 원본 소리도 정상적으로 따라옵니다.
  - 입력 우클릭 메뉴에서 두 번째 디코더 없이 위치·자르기·레이어가 독립된 가상 입력을 만듭니다.
    재생과 소리는 원본을 따라갑니다.
  - 이동/자르기 모드, 화면 손잡이와 방향별 슬라이더로 레이어를 직접 자릅니다.
  - 입력 설정에서 위치와 자르기를 실시간으로 보고, 입력 더블클릭으로 설정을 엽니다.
  - 입력 썸네일을 6·15·30fps로 선택합니다. Program·녹화·송출은 항상 원래 속도입니다.
  - ⌘W는 도구 창과 시트를 닫지만 메인 스위처와 Display 출력은 닫지 않습니다.
  - 한국어·영어 화면과 화면 지연·렌더러·오디오 언더런 진단을 개선했습니다.


2. 화면 구성 (vMix와 동일)
----------------------------------------------------------------
  [ Preview(주황) | 전환 버튼 · T-바 · FTB | Output(초록) ]
  [ 입력 목록 ........................ | 오디오 믹서 ]
  [ Add Input · Record · External · Stream · MultiCorder · Fullscreen · Overlay · Schedule ... ]

- Preview(주황): 다음에 내보낼 화면. Output(초록): 지금 나가는 화면.
- 입력 상자 클릭 = Preview로, 더블클릭 = 속성, 제목 우클릭 = 접기/펼치기, 드래그 = 순서 바꾸기.
- 입력 상자 버튼: × 닫기 · Quick Play · Cut · Loop · 1~4 오버레이 · 스피커(소리 켜기/끄기).
  · 실수로 닫았으면 위쪽의 [Undo] 버튼으로 바로 되살립니다.
- 모니터 아래 재생 바(동영상): 처음으로 · 재생/일시정지 · 위치 바(클릭·드래그로 이동) · 시간.
  · 위치 바 우클릭 → Mark In / Mark Out (초록/빨강 표시, 그 구간만 재생).
  · 시간 클릭 = 경과 ↔ 남은 시간. 끝나기 10초 전부터 빨간색.


3. 기본 조작 / 단축키
----------------------------------------------------------------
  Space        Cut (Preview ↔ Output 즉시 전환)
  Return       Quick Play (기본 0.5초 페이드)
  1 ~ 9        해당 번호 입력을 Preview로
  ⌘1 ~ ⌘9      해당 번호 입력을 바로 Output으로 (Cut)
  ⌥1 ~ ⌥4      전환 버튼 1~4
  ⇧⌘B          FTB (Fade To Black)
  ⌘I           입력 추가
  ⌘N / ⌘O / ⌘S 새 프로젝트 / 열기 / 저장 (5초마다 자동 저장)
  ⌘W           현재 도구 창·시트 닫기 (메인 스위처와 Display 출력은 닫지 않음)
설정(⌘,) → 단축키 탭에서 원하는 키에 어떤 기능이든 지정할 수 있습니다 (vMix 기본 세트 버튼 제공).

- 전환 버튼 4개: 버튼 = 실행, ▾ = 효과(Fade/Merge/Wipe/Fly 등), 숫자 = 시간(ms).
- T-바: 위로 밀면 첫 번째 효과로 수동 전환.
- Stinger 1·2: 투명 배경 애니메이션(ProRes 4444 MOV 등)으로 전환. ▾에서 미디어와 컷 지점 지정.


4. 입력 추가 (Add Input)
----------------------------------------------------------------
- 카메라/캡처: 내장 카메라, USB/Thunderbolt 캡처(UltraStudio, Magewell, Elgato 등).
  포맷: "자동"이면 프로그램 프레임에 맞추고, 목록에서 장치가 지원하는 해상도·프레임을 직접 고를 수도 있습니다.
- 미디어 파일: MP4, MOV(ProRes 4444 알파 포함), MXF, TS, MKV, MP3, WAV 등.
  FFmpeg 네이티브 디코더와 AV1(libdav1d), VP8/9(libvpx), Opus 디코더를 포함합니다. 확장자만으로 내부 코덱 지원이 보장되지는 않습니다. VideoToolbox 하드웨어 디코드가 가능하면 사용하고, 불가능하면 CPU 디코드로 전환합니다.
  입력 타일은 480×270·최대 12fps 모니터 프록시를 사용하지만, 원본 파일 디코드는 계속 필요합니다. Preview/Program 화질은 원본을 유지합니다.
- 스트림: SRT(Caller/Listener/Rendezvous, 암호, Stream ID), RTMP(받기), UDP, URL.
  · SRT Latency는 상대와 같게, 왕복 지연(ping)의 4배 이상. LiveU 등은 srt://내IP:포트 로 Caller 접속.
- NDI: 같은 네트워크의 NDI 소스 자동 검색 (다른 서브넷은 설정 → 네트워크에 IP 추가).
- 컬러: 컬러바, 검정, 흰색, 사용자 색(불투명도 포함), 투명.
- 이미지: PNG(투명 지원), JPG 등.
- 타이틀: 자막 템플릿 24종 (아래 6장).
- 화면/창 캡처, 웹 브라우저(Chromium 내장, 마우스·키보드 조작 가능), 오디오 입력.

신호 끊김 / 백업: 입력 속성 → General에서 "끊겼을 때 화면", "백업 입력"을 정하면
라이브 입력(SRT·NDI·카메라)이 끊길 때 자동으로 백업으로 넘어갔다가 신호가 돌아오면 복귀합니다.


5. 위치 · 분할 화면 (Layers)
----------------------------------------------------------------
[위치 드래그] 모니터 오른쪽 위 [위치] 버튼 → 상자를 끌어 이동, 노란 모서리로 크기 조절.
  초록 가이드선(중앙·가장자리·안전 영역)에 붙습니다. Output에서는 송출 중인 오버레이도 옮길 수 있습니다.
  우클릭: 위치 초기화 · 가운데 정렬 · 화면 맞추기.
[Safe Area] Preview 오른쪽 위 점선 사각형 버튼: 90%/80% 안전 영역 표시.
[화면 맞춤·축별 줌] 입력 ⚙ › 위치에서 맞추기·꽉 채우기(잘림)·늘리기를 고릅니다.
  가로·세로 줌 따로를 켜면 LED 와이드 화면에 맞게 X/Y 크기를 별도로 조절할 수 있습니다.
  API: SetFitMode Value=fit|fill|stretch · SetZoomX / SetZoomY.

[분할 화면 — 4분할·9분할 등]
  1) Add Input → 컬러 → "투명"(또는 원하는 바탕색) 추가
  2) 그 입력의 ⚙ → 속성 → Layers 탭
  3) [템플릿 적용]: 2분할 · 3분할 · 4분할(2×2) · 9분할(3×3) · 16분할 · 1+3 · 1+5 · PIP 등
  4) 칸마다 입력 선택 (또는 [입력 자동 배치]), 채우기/맞추기, 간격·테두리 조절
  5) 미리보기에서 칸을 드래그해 미세 조정 → 이 입력을 Output이나 오버레이로 내보내면 끝
  API: SetLayer Input=분할입력 Value=칸번호,입력  /  LayerLayout Input=분할입력 Value=quad|nine|…


6. 자막 (타이틀 템플릿)
----------------------------------------------------------------
Add Input → Title에서 미리보기를 보고 고릅니다.
  하단 자막 7종 · 포커 4종 · 전체 화면 5종 · LIVE/소셜/로고 · 카운트다운/시계/스코어보드 · 티커 2종
⚙ → 타이틀 편집:
  - 큰 미리보기에서 글자·박스를 드래그해 위치/크기 변경
  - 글자, 색, 그라데이션, 그림자, 외곽선, 폰트, 등장 효과(페이드·슬라이드·와이프·팝)
  - 필드 추가/삭제, 프리셋 저장, 카운트다운 시작/정지
  - [내 템플릿으로 저장] → Add Input 목록에 ★로 표시, [파일로 내보내기]로 다른 맥과 공유
API: SetText Input=번호 SelectedName=Headline.Text Value=내용


7. 오디오
----------------------------------------------------------------
- Master와 "사용 중인 버스"를 항상 표시합니다. 미디어 입력은 파일을 분석할 때 오디오 트랙을 확인해 재생 전부터 스트립을 표시하고, 오디오 트랙이 없는 입력은 공간 절약을 위해 숨깁니다. 라이브 입력은 실제 오디오가 들어오면 표시합니다. [+ Bus]로 버스 A~G 추가.
- 믹서 제목 옆 파형 버튼은 레벨 미터만 접고 펼칩니다. 오른쪽 화살표는 입력 채널 스트립 전체를 접고 펼칩니다. 입력별 ⚙ 속성 › Audio Settings › Visible in Mixer로 개별 표시도 설정할 수 있습니다.
- 격자 아이콘 = 오디오 버스 매니저(입력 × 버스 한 화면 라우팅).
- 채널마다: 페이더, 음소거, M/A/B 버스, Solo(헤드폰), → (Audio Auto: 화면이 Output일 때만 소리), ⚙ 오디오 설정
  (EQ·컴프레서·게이트·딜레이·채널 모드).
- 헤드폰 볼륨 + [모니터]로 맥 기본 출력에서 듣기.


8. 출력 · 녹화 · 송출
----------------------------------------------------------------
- Stream: RTMP(YouTube, Twitch 등), SRT(Caller/Listener), 사용자 URL. 하드웨어 인코더 사용.
- Record: MP4/MOV/MKV/MPEG-TS, H.264/HEVC/ProRes, N분마다 새 파일.
- External: DeckLink(SDI/HDMI) 출력.  NDI 출력: 네트워크로 프로그램 송출.
- MultiCorder: 입력별 개별 녹화(ISO).
- Fullscreen: 다른 모니터에 Output/Preview/멀티뷰 전체 화면 (Esc·더블클릭·우클릭으로 닫기).
- Overlay: 오버레이 1~4 효과·시간·PIP 위치, Stinger 설정.
- Schedule: 정해진 시각/요일에 송출 시작·녹화·컷 등 아무 기능 자동 실행.
- 스냅샷(카메라 아이콘): 현재 Output을 PNG로 저장.
- 새 영상 입력은 기본으로 Loop가 꺼집니다. 설정 › 일반 › 재생 › 새 영상 입력 기본 루프에서 변경합니다.
- 송출 대상이 연결 중·재연결·오류 상태면 STREAM 버튼이 주황으로 깜빡이고, 연결되면 빨간색으로 돌아옵니다.
- 설정 창이 열린 상태에서도 종료되며, 맥 잠자기·깨우기는 프레임 드롭이 아닌 경고로 기록됩니다.


9. 상태 확인
----------------------------------------------------------------
- 위쪽: FPS · Render(렌더 시간) · Max · Drop. Render가 프레임 시간(59.94p ≈ 16.7ms)보다 작으면 정상.
- Statistics(막대 아이콘): 입력별 실제 fps·흔들림·늦은 프레임, SRT 상태(RTT·손실·버퍼), 출력 비트레이트,
  최근 2분 상태 그래프(렌더 시간·드롭·비트레이트·SRT).
- Output 화면 경고: FADE TO BLACK, LOW VOLUME(송출/녹화 중 무음 5초 이상) — 화면에만 보이고 송출에는 안 나갑니다.


10. 원격 제어 (vMix 호환 API)
----------------------------------------------------------------
- 원격 제어는 기본으로 꺼집니다. 아래 기능을 쓰기 전에 설정 › 네트워크 › 원격 제어에서 켜세요.
- 웹 리모트: 브라우저에서 http://맥IP:8088/
- 휴대폰 탤리: http://맥IP:8088/tally
- vMix Web API: http://맥IP:8088/api/?Function=Cut  ·  TCP 8099 (vMix TCP API)
  Companion, Stream Deck, vMix용 컨트롤러가 그대로 동작합니다.
- 보안: 설정 › 네트워크 › 원격 제어 — 켜기, 허용 범위(같은 네트워크/이 맥에서만), 허용 IP, 웹·HTTP 비밀번호.
  다른 웹사이트가 브라우저를 통해 보내는 명령은 항상 차단됩니다.


11. 언어
----------------------------------------------------------------
설정(⌘,) → 일반 → 언어 / Language: 한국어 / English. 바로 바뀌며 송출·녹화는 계속됩니다.


12. 문제 해결
----------------------------------------------------------------
- 앱이 안 열림: 우클릭 → 열기 (1장 참고).
- 카메라/마이크가 안 보임: 시스템 설정 → 개인정보 보호 및 보안 → 카메라/마이크에서 HongMix 허용.
- 화면 캡처가 느림: 화면 및 시스템 오디오 녹음 권한 허용.
- NDI 소스가 안 보임: 로컬 네트워크 권한 허용, 다른 대역이면 설정 → 네트워크에 IP 추가.
- SRT가 끊김/깨짐: Statistics의 SRT 표에서 RTT·손실 확인 → Latency를 RTT의 4배 이상으로.

13. 방송 운영 도구 (1.1에서 추가)
----------------------------------------------------------------
[방송 딜레이 + DUMP]
  Stream/Record 출력 설정 › 인코딩 › "방송 딜레이"(5초~6시간). 인코딩된 영상을 그만큼 늦게 내보냅니다(화질 손실 없음).
  위쪽에 "DELAY 이름 · 보관 중인 시간"이 보이고, 사고가 나면 빨간 [DUMP] → 아직 안 나간 지연 구간을 버리고 즉시 실시간으로.
  API: SetDelay Value=초 / DelayDump
  보관 위치: 자동(1분 이하는 메모리, 그 이상은 디스크) / 메모리 / 디스크. 디스크 방식은 고른 폴더(기본: 캐시 폴더)에
  1분 단위 조각 파일로 쌓고, 내보낸 조각은 바로 지웁니다. 설정 화면에 필요한 용량·남은 공간·현재 비트레이트로 몇 시간까지
  되는지가 표시됩니다. 딜레이 용량 + 여유 2GB가 안 되면 시작하지 않고 알려 주며, 방송 중 디스크가 차면 이후 구간은
  메모리로 이어 갑니다(위쪽 표시에서 "DISK"가 사라짐).

[송출 전 점검] 아래쪽 체크리스트 아이콘
  Output 신호, 라이브 입력, 백업 지정, SRT 품질(손실·지연), 송출 주소·키, 녹화 디스크 남은 시간, 오디오(무음·클리핑),
  렌더러, FTB 상태를 초록/노랑/빨강으로. Stream 버튼을 누를 때 문제가 있으면 자동으로 이 창이 뜹니다.

[런다운 (큐시트)] 아래쪽 [Rundown]
  방송 순서를 한 줄씩: 제목·길이·메모·실행할 기능(Fade, 오버레이, SetText, 녹화 시작 … 여러 개).
  [NEXT] 한 번에 다음 항목 실행. 항목별 남은/초과 시간, 쇼 전체 진행과 계획 대비 빠름/늦음 표시.
  "지금 화면으로 추가" = 현재 Output·오버레이 상태를 그대로 항목으로. 시간이 되면 자동으로 넘어가기 옵션.
  API: RundownNext / RundownPrevious / RundownGo Value=번호 / RundownReset (Stream Deck·Companion에서 사용)

[실시간 자막 (CC)] 아래쪽 [CC]
  방송 오디오(Master 또는 버스 A~G)를 맥 안에서 음성 인식해 자막 입력에 띄웁니다. 한국어·영어·스페인어·일본어 등.
  번역: 영어/한국어/스페인어 등으로 동시 번역 줄 추가 (macOS 번역 언어를 처음 한 번 내려받아야 함).
  [자막 입력 추가] → 생긴 '실시간 자막' 입력을 오버레이로 올리면 방송에 나갑니다.
  끝나면 ~/Movies/HongMix 에 .srt 자막 파일이 저장됩니다(다시보기 편집용).
  처음 시작할 때 '음성 인식' 권한을 허용하세요.

[상황판] 아래쪽 심장박동 아이콘 (색 = 가장 나쁜 SRT 링크 상태)
  SRT 링크: 입력·출력마다 신호등, RTT·손실·전송률 그래프(2분), 추천 Latency 값, 손실/드롭 이벤트.
  사고 기록(블랙박스): 송출·녹화 중 신호 끊김·프레임 드롭·무음·SRT 손실·출력 오류가 생기면
  전후 약 10초 Output 화면과 기록을 ~/Movies/HongMix/Incidents 에 자동 저장. [보고서 저장]으로 텍스트 보고서.

[카테고리 · 검색] 입력 목록 왼쪽 색 탭
  ALL + 6색. 입력의 ⚙ 메뉴 › 카테고리로 지정, 탭을 누르면 그 색 입력만. 탭 우클릭 = 이름 바꾸기. 돋보기 = 이름/번호 검색.

[녹화 남은 시간] 녹화 중 위쪽에 "녹화 3.2시간 남음" (디스크 여유 ÷ 현재 비트레이트).

14. 1.2에서 추가된 기능
----------------------------------------------------------------
[카운트다운 자동 시작] 카운트다운 자막을 Output이나 오버레이에 올리면 바로 줄어들기 시작합니다.
  다 끝난 상태였으면 처음 시간부터 다시. 끄려면 ⚙ › 자막 편집 › 카운트다운 › "자동 시작" 해제.

[트리거 (Triggers)] 입력 ⚙ › 속성 › Triggers 탭
  이벤트가 생기면 기능을 자동 실행: Output으로 들어갈 때 / 빠질 때, 오버레이로 들어갈 때 / 빠질 때,
  영상 재생이 끝났을 때(OnCompletion), 카운트다운이 0이 됐을 때.
  예) 오프닝 영상 끝 → 카메라1로 Fade · 카운트다운 0 → 오프닝 영상으로 Cut · 자막이 올라가면 BGM SetVolume 40.
  입력 칸에 "이 입력"을 고르면 자기 자신. "…ms 후"로 지연 실행, ▶ 버튼으로 바로 시험.

[리스트 입력 (List)] 입력 추가 › Video › Browse…에서 파일을 여러 개 고르면(⌘/⇧ 클릭) 차례로 재생합니다.
  속성 › List 탭: 파일 추가 · 삭제 · 순서 ↑↓ · 섞기 · 더블클릭 = 그 항목 재생 · "리스트 반복".
  API: NextItem · PreviousItem · SelectIndex Value=n · ListAdd Value=경로 · ListRemove Value=n · ListShuffle

[SRT 이중 경로 · 리턴 피드] 출력 설정(Stream ⚙)
  - "보조 경로 추가": 같은 설정의 출력을 하나 더 만들고 주소만 두 번째 서버/회선으로 바꾸면
    Stream 버튼 한 번으로 두 경로가 동시에 나갑니다 (한쪽 회선이 끊겨도 방송 유지).
  - 출력 추가 › "리턴 피드": 현장(진행자·카메라맨)에게 프로그램 화면을 되돌려 보내는 SRT 리스너
    (포트 9998, 2.5 Mbps, 지연 300 ms). 현장 장비/앱에서 srt://이 맥의 IP:9998 로 콜러 접속.
    리턴 피드는 Stream 버튼과 따로 움직입니다 (방송을 멈춰도 계속 나감).

[자동 더킹] 입력 ⚙ › 속성 › Audio Settings › 자동 더킹
  진행자 마이크에 "이 입력이 말하면 다른 소리를 줄임", 음악·영상에 "다른 입력이 말할 때 이 입력을 줄임".
  줄이는 양(기본 −15 dB) · 감지 레벨(−38 dB) · 복귀 시간(0.9초).
  API: DuckingOn / DuckingOff / SetDuckTrigger · SetDucked Input=… Value=On|Off

[멀티트랙 녹화] Record ⚙ › 멀티트랙 오디오 › 추가 트랙에 버스(M, A–G)를 켭니다.
  트랙 1 = 오디오 버스(보통 Master), 트랙 2부터 켠 순서대로 버스. 편집 프로그램에서 마이크/음악을 따로 다시 믹스.
  API: SetRecordAudioTracks Value=AB

[LUT] 입력 ⚙ › 속성 › Colour Adjust › LUT (3D .cube) → 파일 선택, 강도 0–100 %.
  S-Log3, V-Log, C-Log 같은 Log 카메라를 Rec.709로 바꾸거나 룩을 입힙니다 (GPU 처리).
  API: SetLUT Input=… Value=/경로/파일.cube · SetLUTStrength Value=0–1

[스코프] 하단 파형 아이콘 → 별도 창 (두 번째 모니터에 띄워두기 좋음)
  웨이브폼(휘도, 0/25/50/75/100 % 선) · RGB 퍼레이드 · 벡터스코프(75 % 컬러바 목표점, 피부톤 선) · 히스토그램.
  소스: Output / Preview / 아무 입력. 오른쪽 위에 클리핑(100 % 이상)과 블랙(0 %) 비율.

문의·의견: github.com/HongMix/HongMix/issues

15. 2.0.5 새 기능
----------------------------------------------------------------
[PTZ] 하단 PTZ 버튼은 옮길 수 있는 별도 제어 창을 엽니다. 1~9로 카메라 선택, W/A/S/D 이동,
Q/E 줌, Z/X 포커스, F 자동 초점과 창에 표시된 프리셋 키를 사용합니다. 입력 ⚙ › PTZ에서 카메라별로
설정합니다. 키를 떼거나 PTZ 창에서 벗어나면 카메라 이동이 멈춥니다.

[Finder 파일 드롭] 영상·이미지·사진 폴더·PDF를 입력 영역에 놓으면 새 입력이 생깁니다. 여러 영상을
Option 키와 함께 놓으면 List 하나로 만들고, Command 키와 함께 기존 타일에 놓으면 확인 후 파일을 교체합니다.

[MIDI] 설정 › MIDI에서 학습 모드, 컨트롤러 템플릿, LED 탤리를 설정합니다. 방송 전 모든 할당을 시험하세요.

[녹화 안전] Record ⚙에서 예상 녹화 가능 시간을 보고, 두 번째 디스크에 동시에 백업하거나 첫 디스크가
차면 다른 디스크로 이어서 녹화할 수 있습니다. Stream 옆 송출 모니터는 비트레이트·드롭·SRT RTT/손실·재연결을 보여 줍니다.

[새 입력] 입력 추가에서 Photos·PDF 슬라이드·Virtual Set을 선택할 수 있습니다. PowerPoint·Keynote·
Google Slides는 PDF로 내보낸 뒤 PDF 슬라이드로 추가하세요.

16. 2.0.9 새 기능
----------------------------------------------------------------
[AI 배경 제거] 입력 ⚙ › Key에서 크로마키 없이 사람만 남깁니다. 투명·블러·이미지 배경과 Fast·Balanced·
Accurate 품질을 고릅니다. 59.94p는 Fast를 권장하며 방송 전 실제 카메라와 조명으로 시험하세요.

[리플레이 내보내기] 클립의 ⬇를 누르고 여러 개는 Command-클릭합니다. 16:9·9:16·1:1, 한 각도/모든 각도,
일반·50%·AI 슬로모션, 0~2초 핸들, H.264·HEVC·ProRes를 지원하며 백그라운드에서 처리합니다.

[자막] Tools › Captions에서 오른쪽 열·시네마·밴드·사용자 디자인을 설정합니다. macOS 26 이상은 끊지 않는
온디바이스 새 엔진과 실제 발화 시각 SRT를 사용하고 이전 macOS는 기존 엔진으로 동작합니다. 최소 줄 표시
시간으로 읽기 속도를 정하고 필요하면 한국어 용어집·교정 파일을 교체할 수 있습니다.
