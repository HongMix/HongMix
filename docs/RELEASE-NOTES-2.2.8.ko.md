# HongMix 2.2.8 (빌드 141)

HongMix 2.2.8은 실제 Wi-Fi 환경에서 브라우저 스위처가 더 부드럽고 안정적으로 동작하도록 개선한 버전입니다. 별도로 배포하지 않은 2.2.6·2.2.7 작업을 포함하며, 이전 공개 버전은 2.2.5입니다.

## 브라우저 실시간 화면

- Preview와 Program이 가끔 바뀌는 정지 그림 대신 실시간 MJPEG 화면을 사용합니다.
- 웹 리모트에서 **부드럽게(15 fps)**·**보통(8 fps)**·**데이터 절약(2 fps)**을 선택합니다.
- 실시간 화면을 최대 16개로 제한해 Mac 부하를 관리하고, 지원 범위 밖의 프레임레이트와 너비는 안전한 값으로 맞춥니다.
- 썸네일 인코딩을 명령 처리와 분리해 Cut·오버레이·재생 명령이 이미지 처리 뒤에서 기다리지 않습니다.

## Wi-Fi 안정성과 탈리

- Wi-Fi가 끊기면 웹 요청이 빠르게 종료되고 **연결 끊김 — 다시 연결 중…**을 표시한 뒤 계속 재연결합니다.
- 페이지를 닫지 않고 사라진 휴대폰 연결은 몇 분이 아니라 약 8초 안에 정리합니다.
- 탈리 요청이 겹치지 않게 해 느린 회선에서 오래된 응답이 이전 불빛을 잠깐 되살리던 현상을 막았습니다.
- 아무 데이터도 보내지 않거나 헤더가 나뉘어 들어오는 연결도 제한 시간과 크기 안에서 안전하게 처리합니다.

## 더 정확한 접속 모드 표시와 요청 보안

- **이 맥에서만** 모드는 `localhost`를 표시하고, 휴대폰에서는 접속할 수 없다는 안내를 보여 줍니다.
- **같은 네트워크의 장비** 모드는 휴대폰·태블릿에서 사용할 LAN 주소를 계속 표시합니다.
- HongMix 웹 페이지와 직접 입력한 주소·API 요청은 허용하면서, 관련 없는 다른 웹 페이지가 보내는 명령은 거부합니다.

## 설명서

- [한국어 설명서](manual/HongMix-Manual.ko.md)와 [English manual](manual/HongMix-Manual.en.md)에 휴대폰에서 리모트가 열리지 않을 때의 확인 순서를 추가했습니다. 같은 Wi-Fi, 접속 허용 모드, `https`가 아닌 `http`, 게스트 네트워크 격리, VPN을 차례로 확인합니다.
- 기존 설명서 캡처는 2.2.5 브라우저 배치를 보여 줍니다. 현재 화면을 설명하는 데 사용할 수 있지만, 새 2.2.8 화질 선택 메뉴는 보이지 않습니다.

## 검증

- 가상 스위처 화면 검사: 데스크톱 65/65, 아이패드 65/65, 휴대폰 66/66.
- 실제 앱 연동 검사: 47/47, 드롭 프레임 0.
- 웹 보강 검사: 10/10.
- 10분 부하 시험: 요청 10,495개, 명령 797개 중 실패 0, 드롭 프레임 0, 메모리 522–558MB, 시험 종료 뒤 남은 실시간 연결 0.
- 릴리스 후보의 코어·번역·체크섬·DMG·애드혹 앱 서명 검사를 통과했습니다.

## 알려진 제한

- 실제 아이폰·아이패드 기기 시험은 아직 남아 있습니다. LAN 주소 접속, 휴대폰 크기 화면, Cut 동작은 이 Mac의 브라우저에서 확인했습니다.
- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
