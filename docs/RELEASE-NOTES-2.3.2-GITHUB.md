# HongMix 2.3.2 · build 151

> 시스템 메뉴 언어를 바로잡고 PDF·사진 슬라이드 단축키를 추가했습니다. System menu language is fixed, with new PDF / Photos slide shortcuts.

## 한국어

- 영어·다른 언어 맥에서 편집·윈도우·서비스 메뉴와 파일 열기 창이 한국어로 나오던 문제 수정
- macOS가 그리는 부분도 **설정 › 일반 › 언어**의 HongMix 언어 설정을 따름
- **설정 › 단축키**에 **NextPicture**와 **PreviousPicture** 추가
- 입력을 비우면 Program에 송출 중인 PDF·사진 슬라이드를 넘기며, 없으면 Preview 입력을 사용

## English

- Fixes the Edit, Window and Services menus and open-file panels showing Korean on English and other-language Macs
- macOS-provided interface elements now follow **Settings › General › Language**
- Adds **NextPicture** and **PreviousPicture** to **Settings › Shortcuts**
- Leave the input empty to control the PDF / Photos slides on Program, falling back to Preview
