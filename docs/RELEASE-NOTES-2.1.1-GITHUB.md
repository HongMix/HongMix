# HongMix 2.1.1

## 한국어

- 방송 중 방해 금지: 실행할 때 켜고 종료할 때 끄며 상단 버튼으로 전환합니다(처음 한 번 단축어 승인).
- 시작 전 점검: 맥 상태, 네트워크 IP·속도, 원격 제어 주소와 장비를 한 화면에서 확인합니다.
- 모니터별 출력과 디스플레이 재연결 자동 복구를 추가했습니다.
- 디스플레이를 모든 데스크톱에 고정하거나 현재 데스크톱에서만 보이게 할 수 있습니다.
- 다른 앱이 키보드를 가져가면 주황 경고 줄이 나타납니다.
- 화면 꺼짐 방지, 첫 실행 언어 자동 선택, 실시간 자막 번역을 개선했습니다.

## English

- Do Not Disturb can turn on with HongMix, restore on quit and toggle from the top bar after one Shortcut approval.
- The pre-show check shows Mac health, network IP/speed, remote-control addresses and devices.
- Per-monitor outputs return automatically after a display is reconnected.
- Display output can stay on every desktop or only the current desktop.
- An orange bar warns when another app owns the keyboard during a live output.
- Display-sleep prevention, first-launch language and live-caption translation were improved.
