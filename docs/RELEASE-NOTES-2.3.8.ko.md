# HongMix 2.3.8 (빌드 173)

**2.3.7 사용자 모두에게 업데이트를 권장합니다.** HongMix 2.3.8은 하드웨어 룩을 켰을 때 실행, 컷과 트랜지션 중 Program 프레임이 끊기던 문제를 고쳤습니다.

## 고친 내용

- 2.3.7의 하드웨어 룩은 입력 타일 키, 믹서 채널, 페이더 손잡이, Overlay 키, 트랜지션 슬라이더 등 버튼 약 100개에 SwiftUI 그림자를 적용했습니다.
- 화면이 바뀔 때마다 이 그림자를 GPU에서 추가로 그렸고, 실행·컷·페이드 때 Program 합성이 그 작업을 기다릴 수 있었습니다.
- 이제 같은 모양의 가벼운 어두운 바탕 두 겹으로 입체감을 그립니다. 모양은 거의 같고 별도 그림자 처리 부담은 없습니다.

## 측정 결과

운영자의 프로젝트에서 4K 59.94 H.264 영상을 Program으로 재생하고 YouTube 브라우저 입력과 Chrome 대시보드를 켠 상태로 비교했습니다.

| 검사 | 2.3.7 | 2.3.8 |
|---|---:|---:|
| 실행 후 첫 30초 | 드랍 63 | 0 |
| 페이드 20회 | 드랍 34 | 0 |
| 컷 10회 | 드랍 8 | 0 |
| 가장 느린 프레임 | 18.3ms | 3.6ms |

2.3.8 측정을 두 번 반복했으며 검사한 드랍 수가 모두 0이었습니다. Chrome 대시보드는 여전히 GPU를 사용하지만 수정 후에는 드랍을 만들지 않았습니다.

## 검증과 제한

- 번역·핵심 테스트를 통과했습니다. DMG 무결성, 심층 애드혹 서명과 빌드 173 DMG·PKG 체크섬을 확인했습니다.
- 빌드 173은 측정한 빌드 172와 같은 소스지만, 애드혹 서명 때문에 폴더 접근 권한을 다시 물을 수 있어 운영자의 프로젝트로 직접 실행하지 않았습니다.
- 공개 앱은 애드혹 서명이고 아직 Apple 공증 전이며 PKG는 무서명입니다.
