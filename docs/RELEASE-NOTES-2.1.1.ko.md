# HongMix 2.1.1

HongMix 2.1.1은 방송 안전 기능, 시작 전 시스템 점검, 안정적인 다중 모니터 출력을 추가했습니다.

## 새 기능

- **방송 중 방해 금지:** HongMix를 켜면 방해 금지를 켜고 종료하면 원래대로 끌 수 있습니다. 처음 한 번 macOS 단축어를 승인한 뒤 상단 버튼으로 바로 켜고 끕니다.
- **시작 전 점검:** 맥 부하·메모리·디스크·배터리·발열, 모든 네트워크의 IP·속도, 원격 제어 주소, 마이크 권한과 연결된 모니터를 한 화면에서 확인합니다.
- **모니터별 출력:** 연결된 모니터마다 Output, Preview, 버스 또는 입력을 따로 지정합니다. 모니터를 다시 연결하면 같은 할당이 자동 복구됩니다.
- **데스크톱별 디스플레이 출력:** **이 모니터에 항상 고정** 또는 **지금 데스크탑에서만 보기**를 선택합니다. 모니터 하드웨어 정보로 다시 연결된 화면을 찾습니다.
- **키보드 제어 경고:** 방송 출력 중 다른 앱이 키보드를 가져가면 주황 경고 줄이 나타나며, 누르면 HongMix로 돌아옵니다.
- **안전한 운영:** HongMix 실행 중 화면이 자동으로 꺼지지 않으며, 첫 실행 언어는 맥 언어를 따릅니다.
- **실시간 자막:** 계속 말하는 중에도 이전 번역을 취소하지 않고 표시한 뒤 최신 문장을 이어서 번역합니다.

## 추가 API

`SetMonitorOutput`, `MonitorOutput`, `MonitorOutputOff`, `IdentifyMonitors`, `DoNotDisturbOn`, `DoNotDisturbOff`, `DoNotDisturbOnOff`, `StartupCheck`, `ShowStartupCheck`.

## 검증

Apple M1 Max 맥과 Sidecar 화면에서 방해 금지 승인·켜기·끄기, 화면 꺼짐 방지, 한·영 시작 전 점검, 인터넷 속도 측정, 키보드 경고, 모니터 번호 표시, 모니터별 출력, 데스크톱 고정, 화면 분리·재연결 복구, 자막 번역, 빌드와 DMG 검증을 확인했습니다. 실제 HDMI/USB-C 모니터, 3대 이상 모니터, 핫스팟 연결, 한국어가 없는 맥의 첫 실행은 아직 확인하지 못했습니다.
