# HongMix 2.0.5

## 새 기능
- **PTZ Control 창** (하단 바 › PTZ): PTZ 카메라 입력들의 실시간 화면을 1~9번으로 보여 줍니다. 키: 1~9 카메라 선택 · W A S D 이동(Shift = 빠르게) · Q/E 줌 · Z/X 포커스 · F 자동 초점 · U I O / J K L / M , . 프리셋 1~9 · Tab 다음 카메라. 키를 떼면 멈추고, 창을 벗어나면 모든 움직임이 멈춥니다.
- **입력별 PTZ** (입력 ⚙ › PTZ): VISCA over IP(Sony), VISCA TCP(PTZOptics), VISCA UDP, NDI PTZ. NDI 입력은 자동으로 NDI PTZ, SRT·RTSP 입력은 카메라 IP를 자동으로 채웁니다. 프리셋, "Preview에 올리면 프리셋으로 이동"(Program에 나간 카메라는 움직이지 않음).
- **Finder에서 파일 끌어다 놓기**: 입력 영역에 놓으면 새 입력(영상·이미지·사진 폴더 → Photos·PDF → PDF 슬라이드). ⌥ 여러 영상 → List 하나. ⌘ 타일 위 → 그 입력의 파일 교체(항상 확인).
- **MIDI 컨트롤러** (설정 › MIDI): 학습 모드, Akai APC mini mk1/mk2·Korg nanoKONTROL2·Behringer X-Touch Mini 템플릿, LED 탤리.
- **Photos**, **PDF 슬라이드**(PowerPoint·Keynote·Google 슬라이드를 PDF로 내보내기), **Virtual Set** 입력.
- **Desktop Capture 소리**: 창은 그 앱 소리, 화면 전체는 맥 전체 소리(HongMix 제외). "크롬 다시 실행"으로 숨겨진 크롬 창도 계속 그립니다.
- **녹화 안전** (REC ⚙): REC 버튼에 디스크 남은 시간과 경고, 두 번째 디스크 백업 녹화, 디스크가 차면 다른 디스크로 이어서 녹화.
- **송출 모니터** (STREAM 옆): 목적지별 비트레이트 그래프, 드롭, SRT RTT·손실, 재연결 횟수.

## 수정
- 앱이 죽거나 전원이 나가도 녹화 파일이 남습니다(조각 저장 MOV/MP4).
- 녹화 파일을 못 만들면 녹화 중처럼 보이지 않고 오류를 표시합니다. MultiCorder 실패도 표시합니다.
- 네트워크가 잠깐 끊겨도 방송 딜레이 영상을 버리지 않고, 업로드가 막혀도 소리가 앞서가지 않습니다.
- 실시간 소스의 시계 차이를 보정해 장시간 방송에서도 소리가 튀지 않고, 카메라를 다시 방송에 올릴 때 지지직 소리가 나지 않습니다.
- 카메라·캡처카드·오디오 장치를 뺐다 꽂으면 자동으로 다시 연결되고, 맥북 카메라나 마이크로 바뀌지 않습니다.
- 오디오 인터페이스를 다시 꽂으면 오디오 출력과 헤드폰이 복구됩니다.
- "N분마다 새 파일"에서 프레임이 빠지지 않고, 파일 반복 재생이 끊기지 않으며, 디스크가 느려도 리플레이 녹화가 방송 화면을 멈추게 하지 않습니다.
- Desktop Capture에서 다른 데스크탑의 창(전체 화면 크롬 등)도 고를 수 있고, 화면이 멈춰 있어도 No Signal이 되지 않습니다.
- 영어 화면에서 한국어로 나오던 장치·송출 상태 문구 50개를 번역했습니다.

## 검증 (M1 Max)
녹화 60분(소리·영상 차이 −14.8ms, 드롭 0), SRT 송출 60분(−5.3ms), 녹화 중 강제 종료, Display 출력 16/16, 가상 두 번째 모니터 8/8, PTZ(가짜 VISCA 카메라, 바이트 단위)와 키보드, 가상 MIDI 장치, Finder 파일 드래그.
실제 장비로는 아직 시험하지 못함: PTZ 카메라, DeckLink, MIDI 컨트롤러, USB 장치 뽑기·꽂기.
