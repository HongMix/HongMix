# HongMix 2.1.0

- **영상 루프 기본값:** 새 영상 입력은 기본으로 반복 재생하지 않습니다. 설정 › 일반 › 재생에서 변경할 수 있으며 기존 프로젝트의 저장된 루프 상태는 유지됩니다.
- **맞추기·꽉 채우기·늘리기와 X/Y 줌:** LED 와이드 화면과 비표준 비율 소스를 가로·세로 크기로 따로 맞출 수 있습니다.
- **안정적인 종료:** 설정 창이나 입력 칸이 열린 상태에서도 HongMix가 정상 종료됩니다.
- **잠자기 감지:** 맥 잠자기와 덮개 닫힘으로 멈춘 시간은 프레임 드롭 대신 경고로 기록됩니다.
- **명확한 송출 경고:** 연결·재연결·오류 상태에서는 STREAM 버튼과 해당 출력이 주황으로 깜빡입니다.

Apple M1 Max에서 루프 기본값, 맞추기·꽉 채우기·늘리기, X/Y 줌, XML 값과 키보드·메뉴·Apple Event·SIGTERM 종료를 확인했습니다. Metal 빌드와 SRT 코어 테스트도 통과했습니다. 실제 덮개 닫힘 잠자기와 화면의 주황 송출 미연결 표시는 이번 릴리즈에서 직접 확인하지 못했습니다.

## API 추가

- `SetZoomX`, `SetZoomY`
- `SetFitMode`, `SetPositionFit` (`fit|fill|stretch`)
- `SetZoom`은 X/Y를 다시 비례 줌으로 맞추며 XML은 실제 `zoomX`, `zoomY`를 표시합니다.

## 처음 실행

HongMix는 공개용 임시 서명이며 아직 Apple 공증 전입니다. macOS가 실행을 막으면 시스템 설정 › 개인정보 보호 및 보안 › 그래도 열기를 누르거나 `xattr -dr com.apple.quarantine /Applications/HongMix.app`을 실행하세요.
