# HongMix 1.4.1

## 화면과 운용

- 기존 HongMix 기본 스킨을 그대로 유지합니다.
- 설정 > 일반 > 화면 모양에서 `Graphite Broadcast` 스킨을 선택할 수 있습니다.
- Graphite 스킨은 조작 패널과 상·하단 도구 영역만 바꾸며 Preview, Program, 영상 및 오디오 미터 색은 유지합니다.
- 통계 및 모니터링은 독립 창으로 열리며 다른 디스플레이 또는 macOS 데스크톱으로 이동할 수 있습니다.

## Display 출력

- 기존 Fullscreen 버튼을 `Display`로 정리했습니다.
- `출력 창`: 크기 조절, 다른 모니터·데스크톱 이동, macOS 녹색 버튼 전체화면을 지원합니다.
- `디스플레이 전체화면`: 지정한 모니터를 방송 화면으로 채웁니다.
- Program, Clean Program, Preview, Multiview 및 개별 입력을 선택할 수 있습니다.
- 출력 창의 `항상 위에 표시`와 `16:9 비율 고정`을 선택할 수 있습니다.
- 선택한 모드, 디스플레이와 창 옵션은 다음 실행에도 유지됩니다.

## 언어와 진단

- 한국어와 영어 UI를 설정에서 분리해 선택할 수 있습니다.
- 통계 창에 방송 준비도, 입력·장비, 네트워크, 출력 및 상세 진단 탭을 제공합니다.
- 실시간 Program 오디오와 영상 모니터링을 독립 창에서 확인할 수 있습니다.

## 확인 사항

- DeckLink Fill/Key 및 SDI 입출력은 지원 코드가 포함되어 있지만 실제 카드와 Desktop Video 환경별 검증이 필요합니다.
- 이 배포본은 ad-hoc 서명입니다. 다른 Mac에서 경고 없이 배포하려면 Apple Developer ID 서명과 공증이 필요합니다.
