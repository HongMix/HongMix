# HongMix 2.1.4 (빌드 111)

## 업데이트 후 꼭 확인하세요

**원격 제어는 이제 기본으로 꺼집니다.** Companion·Stream Deck·웹 리모트를 쓰시면 **설정 › 네트워크 › 원격 제어**에서 한 번 켜 주세요. 꺼져 있으면 HongMix가 8088·8099 포트를 열지 않습니다. 이전 버전에서 허용 범위를 직접 골랐던 사용자의 선택은 유지됩니다.

## 새로운 기능

- **가상 입력.** 입력 우클릭 › 가상 입력 복사. 같은 화면을 다시 디코딩하지 않고 위치·자르기·레이어가 독립된 입력을 만듭니다. 재생과 소리는 원본을 따라가며 `CreateVirtualInput` API도 지원합니다.
- **레이어 자르기.** 이동/자르기 모드, 주황 손잡이와 좌·우·위·아래 슬라이더로 같은 소스를 다시 불러오지 않고 레이어를 자릅니다.
- **위치 실시간 미리보기.** 입력 설정 › 위치에서 Program과 같은 자르기·줌·배치를 바로 봅니다.
- **vMix 방식 더블클릭.** 첫 클릭은 즉시 Preview로 보내고 두 번째 클릭은 입력 설정을 엽니다.
- **부드러운 입력 썸네일.** 설정 › 일반 › 재생 설정에서 6·15·30fps를 선택합니다. Program·녹화·송출은 항상 원래 프레임을 유지합니다.
- **안전한 ⌘W.** 도구 창과 시트는 닫지만 메인 스위처와 Display 출력은 닫지 않습니다.
- **원격 제어 개인정보 보호.** 새 마스터 스위치는 즉시 적용되며, 끄면 두 제어 포트를 모두 닫습니다.
- **차분한 상태 진단.** 화면 지연 알림은 1분간 정상이면 사라지고, 렌더러는 최근 5분을 기준으로 판정하며, 꺼진 입력의 미터 읽기를 오디오 언더런으로 세지 않습니다.
- **한국어·영어 화면 완성.** 남은 문구와 시작 상태, 언어 전환 목록을 채웠고 영어 번역이 빠지면 빌드가 실패합니다.

## 검증과 제한 사항

- 가상 입력 저장·재실행과 온에어 동작을 59.94fps에서 확인했고 디코더 추가와 렌더 드롭은 없었습니다. 레이어 자르기와 실시간 미리보기도 화면으로 확인했습니다.
- 코어 테스트, 번역 검사와 임시 서명 검증을 통과했습니다.
- 자동 검사는 더블클릭 분기, 자르기 값과 ⌘W 보호 정책을 확인하지만, 실제 마우스 더블클릭·자르기 손잡이 드래그·모든 시트의 ⌘W는 대상 맥에서 한 번 직접 확인해야 합니다.
- 로컬 CBR SRT 왕복은 약 1.84~1.95Mbps, 프레임 드롭·디코드 오류 0이었지만 MPEG-TS의 DTS/PCR 경고가 반복됐습니다. 엄격한 수신 장비 호환성은 추가 개선이 필요합니다.
- 사용자가 들은 오디오 끊김은 재현되지 않았습니다. 맥 스피커·헤드폰·HDMI·USB·DeckLink 실제 청취 경로는 장시간 시험이 더 필요합니다.
- 공개 빌드는 임시 서명이며 Apple 공증 전입니다.
