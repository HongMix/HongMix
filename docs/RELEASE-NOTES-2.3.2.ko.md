# HongMix 2.3.2 (빌드 151)

HongMix 2.3.2는 영어·다른 언어 맥에서 macOS가 그리는 메뉴와 파일 열기 창이 한국어로 나오던 문제를 고치고, PDF·사진 슬라이드를 넘기는 키보드 단축키 기능을 추가했습니다.

## 시스템 메뉴도 HongMix 언어를 따름

- 편집·윈도우·서비스 메뉴, 가리기/보기 명령과 파일 열기 창이 **설정 › 일반 › 언어**에서 선택한 언어를 따릅니다.
- HongMix가 영어와 한국어를 모두 macOS에 등록하며, 다른 언어 시스템에서는 영어를 기본으로 사용합니다.
- HongMix 언어를 바꾼 뒤 앱을 종료하고 다시 열면 macOS가 그리는 모든 항목도 새 언어로 표시됩니다.

## PDF·사진 슬라이드 단축키

- **설정 › 단축키**에서 **NextPicture**와 **PreviousPicture**를 선택할 수 있습니다.
- 단축키의 입력 칸에서 PDF 또는 Photos 입력을 고르거나, 입력을 비워 Program에 송출 중인 슬라이드를 제어할 수 있습니다. Program에 없으면 Preview 입력을 사용합니다.
- API 호출도 입력을 생략하면 같은 방식으로 동작합니다. Program과 Preview에 슬라이드 입력이 모두 없으면 다른 입력을 바꾸지 않고 오류를 반환합니다.

## 검증

- 영어·네덜란드어·독일어·한국어 시스템의 번들 언어 선택을 확인했습니다. 한국어는 한국어로, 나머지는 영어로 선택됐습니다.
- 실제 앱에서 Program, Preview와 입력을 직접 지정한 경우의 이전/다음 동작을 확인했습니다.
- 번역 검사와 코어 테스트를 통과했고, DMG 무결성과 빌드 151 DMG·PKG의 체크섬을 확인했습니다.

## 알려진 제한

- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
