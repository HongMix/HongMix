# HongMix 2.1.2

## 새로운 기능

- **레이어 영상이 부모 입력을 따라갑니다.** 입력이 출력으로 나가면 그 입력의 영상·카운트다운 레이어도 재생되고, 빠지면 각 레이어의 Auto Pause/Restart 설정을 따릅니다. 같은 루프 레이어가 다른 카메라에도 계속 보이면 카메라를 컷해도 끊기지 않습니다.
- **송출 비트레이트 VBR / CBR 선택.** SRT·RTMP 송출에서 VBR 또는 CBR을 고를 수 있습니다. SRT/MPEG-TS의 CBR은 고정 mux rate에 가깝게 전송량도 채웁니다. 맥의 인코더가 CBR을 거부하면 경고 후 capped VBR로 송출합니다.
- **입력 썸네일이 Program 배치를 따라갑니다.** 맞춤·꽉 채우기·늘리기·줌·이동·자르기가 입력 칸에도 반영되며 Fill/Stretch 상태를 표시합니다.
- **독립 입력 모니터 창.** 입력 칸의 모니터 버튼으로 해당 입력만 크게 보는 창을 열 수 있습니다. 탤리·오디오 미터와 안전한 재생 조작만 있는 보기 전용 창입니다.
- **끝난 영상 재생 문제 수정.** 끝까지 재생된 영상을 다시 Play하거나 출력으로 보내면 처음부터 정상 재생됩니다. 출력 영상 멈춤 감시가 예기치 않은 일시정지·디코더 멈춤을 복구하고 사고 기록에 남깁니다.
- **백그라운드 CPU 작업 감소.** 출력에 쓰이지 않는 자막 티커, 오디오 미터와 재생 바의 갱신 비용을 줄였습니다.

## 맥 정리가 필요한 이유

맥을 며칠씩 켜 두면 macOS의 실시간 현황 위젯 같은 시스템 도우미가 꼬여 몇 초마다 WindowServer의 화면 합성을 막을 수 있습니다. 이때 실제 송출 프레임은 정상이어도 HongMix의 Preview·Output 모니터가 0.5~2초씩 멈춰 보일 수 있습니다.

HongMix 2.1.2는 반복되는 UI 멈춤을 감지해 CPU를 많이 쓰는 원인을 알려주고 **정리하기**를 제공합니다. 다른 앱이나 설정은 건드리지 않고 문제가 된 macOS 위젯 도우미만 재시작하므로 재부팅이 필요 없습니다. 24시간 무인 운영을 위한 자동 정리 옵션과 방송용 맥 1회 설정 가이드도 포함했습니다.

## 검증 및 남은 사항

- 코어 녹화·파일 입력·SRT 루프 테스트를 통과했고, 공개 설치 파일은 2.1.2 build 109 애드혹 서명본입니다.
- 29개 입력 부하 테스트에서 출력 드롭 0을 기록했고 4K·10-bit 컷/페이드를 반복해도 영상 재생이 유지됐습니다.
- CBR 코드와 fallback은 빌드·코어 테스트를 통과했지만, 실제 SRT 수신 파일로 전송량이 일정한지는 아직 측정하지 않았습니다.
- 보고된 오디오 끊김은 테스트 중 듣기용 출력 장치가 없어 재현하지 못했습니다. 실제 청취 경로 확인이 필요합니다.
- 레이어 영상 동작은 실제 방송 프로젝트에서도 한 번 더 확인해야 합니다.
- 아직 Apple 공증 전입니다.
