# HongMix 2.2.3 (빌드 128)

HongMix 2.2.3은 SRT를 수신하는 모든 사용자에게 권장하는 업데이트입니다. 배포하지 않은 2.2.1의 수신 경로 수정·연결 도구와 2.2.3의 사고 원인 자동 판정·통계 수정을 함께 포함합니다.

## SRT 수신 안정성

- 특히 60fps에서 SRT 입력이 몇 분마다 끊기던 문제를 수정했습니다. HongMix가 라이브 스트림을 실제보다 약 2.7% 느리게 소비해 수신 버퍼가 계속 커지고 패킷이 버려졌습니다. 이제 버퍼가 설정한 Latency 근처에서 일정하게 유지됩니다.
- 수정 후 실제 회선에서 Latency 1,000ms와 200ms 모두 버퍼가 일정하고 드롭·신호 끊김이 0이었습니다. 로컬 리스너·콜러·출력 시험도 SRT 오류 없이 끝났습니다.

## 빠른 SRT 설정

- SRT·RTMP·UDP 스트림 입력 타일을 더블클릭하면 연결 설정을 바로 엽니다. 다른 입력은 기존처럼 일반 입력 설정을 엽니다.
- 최근 SRT 연결을 자동으로 기억하고 즐겨찾기를 이름 붙여 저장합니다. 한 번 클릭하면 값을 채우고 더블클릭하면 채운 뒤 다시 연결합니다. 암호 문구는 표시하지 않습니다.
- 회선 안내에서 RTT·손실·최근 드롭과 한 번에 적용하는 권장 Latency를 확인합니다.
- API XML에 상대 주소와 암호를 제외한 `<inputSrtStats>`를 제공합니다.

## 사고 원인 진단

- 송출 중 SRT 입력에서 신호나 패킷이 빠지면 사고 기록에 버퍼·Latency·RTT·손실·드롭·수신 전송률·fps와 자동 판정을 남깁니다.
- SRT 사고 폴더의 `srt.txt`에는 판정과 직전 30초 상태를 초당 한 줄로 저장하며 재전송 수도 포함합니다.
- 연결 종료·송신 중단, HongMix의 느린 소비, 부족한 Latency, 보내는 쪽 드롭, 회선 손실을 구분합니다.
- API·모니터·화면이 서로 통계 카운터를 초기화해 SRT 전송률·손실·재전송이 0 또는 잘못된 값으로 보이던 문제를 수정했습니다.

## 검증

- 로컬 송신기를 강제 종료하자 끊기기 직전 값과 30줄 기록을 남겼습니다.
- 송신 대역폭을 영상 비트레이트보다 낮게 제한하자 손실 약 42%, 재전송 0과 함께 보내는 쪽 드롭으로 판정했습니다.
- HongMix의 느린 소비와 복구되지 않은 회선 손실 판정은 관리자 권한 네트워크 조정이 필요해 일부러 발생시키지 못했습니다. 검증한 동일 측정값의 임계치로 판정합니다.
- 코어 테스트·번역·체크섬·DMG·애드혹 앱 서명 검증을 통과했습니다.

## 알려진 제한

- 입력 타일 더블클릭·최근 목록 선택·이름 입력 창은 더 많은 직접 조작 검증이 필요합니다.
- 암호 문구는 프로젝트 암호처럼 앱 설정에 저장하며, 애드혹 서명 업데이트 때마다 확인창이 생기는 Keychain에는 저장하지 않습니다.
- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
