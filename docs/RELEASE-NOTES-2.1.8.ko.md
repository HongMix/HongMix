# HongMix 2.1.8 (빌드 119)

HongMix 2.1.8에는 2.1.7의 위치·레이어·AI 화질 올리기·성능 개선과 새 프리셋·다중 레이어 편집이 모두 들어 있습니다.

## 레이어 위치 프리셋

- 레이어의 위치·크기·자르기·회전·불투명도·테두리와 채우기/맞추기를 이름으로 저장해 어느 입력·프로젝트의 레이어에도 적용합니다.
- 프리셋은 앱 전체에 저장되고 앱을 다시 켜도 남습니다. 레이어 소스 입력·표시 여부·잠금은 바꾸지 않습니다.
- 메뉴에서 이름 변경과 삭제를 지원하며 프리셋 적용은 한 번의 되돌리기 단계입니다.
- `LayerPreset`, `LayerPresetSave`로 Companion·Stream Deck에서 제어할 수 있습니다.

## 여러 레이어 한꺼번에

- 화면에서 Shift-클릭 또는 Command-A로 여러 레이어를 선택해 함께 이동하거나 화살표로 조정합니다.
- 왼쪽·가로 가운데·오른쪽·위·세로 가운데·아래 정렬, 가로/세로 간격 맞추기, 너비·높이·전체 크기 맞추기를 지원합니다.
- 선택 상자·화면·처음 선택한 상자를 정렬 기준으로 고릅니다. 잠긴 레이어는 움직이지 않습니다.
- 움직이는 상자는 다른 표시 레이어의 가장자리와 가운데에도 스냅됩니다.
- 회전한 레이어도 자르기 손잡이를 끌면 회전하지 않은 레이어처럼 그 상자 변이 움직입니다.

## 2.1.7에서 포함된 기능

- 정확한 숫자칸과 −/+ 조정, 1px 화살표 이동, 되돌리기, 화면 밖 상자를 위한 회색 여백.
- 레이어 불투명도·회전·잠금, 화면에 맞추기·가운데·원래 비율·전체 화면·위치 복사/붙여넣기.
- 레이어 자르기·투명 배경 잘라내기 수정과 이전 프로젝트 자동 변환.
- 지원되는 저해상도 송출 소스의 선택형 AI 화질 올리기와 레이어 합성 캐시 성능 개선.

## 안정성과 검증

- 빌드 119에서 잠긴 레이어 사이의 간격, 많이 자른 손잡이의 상자 튐, 프리셋 중복 이름, 손상된 저장값과 오래된 드래그 상태 등 검토 결과 7건을 수정했습니다.
- 10분 자동 시험에서 프리셋을 약 85회 적용하며 전환·레이어 변경·업스케일 켜기/끄기를 반복했습니다. 프레임 빠짐 0, 오류 0, 재시작 0이며 메모리는 344~450MB로 일정했습니다.
- 코어 테스트·번역·체크섬·DMG·애드혹 앱 서명 검증을 통과했습니다.

## 알려진 제한

- 실제 Shift-클릭·그룹 드래그·스냅·회전 레이어 자르기·Command-A·화살표 키·프리셋 이름 창은 더 많은 직접 조작 검증이 필요합니다.
- 회전 레이어의 정렬과 간격은 회전 전 상자를 기준으로 계산합니다.
- 프리셋은 프로젝트 파일이 아닌 앱 전체에 저장되므로 프로젝트를 다른 Mac으로 옮겨도 함께 이동하지 않습니다.
- 되돌리기 기록은 현재 앱 실행 중에만 유지됩니다.
- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
