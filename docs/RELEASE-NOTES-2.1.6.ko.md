# HongMix 2.1.6 (빌드 114)

## 새 기능

- **위치·레이어를 화면에서 편집합니다.** 안쪽을 끌면 이동, 노란 모서리는 크기, 주황 손잡이는 자르기, Option-끌기는 보이는 부분 이동입니다. 모드 전환이 필요 없고 값은 출력 픽셀로 표시합니다.
- **미리보기가 계속 보입니다.** 위치·레이어 탭은 Program과 같은 화면을 오른쪽에 고정하고 왼쪽 설정만 스크롤합니다.
- **투명 여백 자동 자르기.** 자막·PNG 레이어의 빈 알파 영역을 제거해 전체 투명 캔버스가 아닌 실제 그래픽으로 채우기를 적용합니다.
- **2.1.5 가상 입력 오디오 수정.** 가상 입력이 송출되고 원본 입력 오디오가 AUTO일 때 원본 소리가 영상을 정상적으로 따라옵니다.

## 검증

- 1080p59.94 그래픽 테스트에서 위치 화면의 배치와 픽셀 값이 Program 계산과 일치했습니다.
- 레이어 2개를 넣었을 때 목록·픽셀 입력·자르기 값·선택 손잡이가 정상적으로 그려졌습니다.
- 코어 테스트, 번역 검사, 설치 파일 체크섬과 애드혹 서명 검증을 통과했습니다.

## 알려진 제한

- 실제 마우스 이동·크기·자르기·Option-끌기와 투명 여백 자동 자르기는 더 많은 직접 조작 검증이 필요합니다.
- 레이어 잠금과 레이어 간 위치 복사·붙여넣기는 아직 없습니다.
- 입력 크기 조절은 비율을 유지합니다. 독립 가로·세로 줌은 기존 슬라이더로 설정합니다.
- 공개 빌드는 애드혹 서명이며 아직 Apple 공증 전입니다.
