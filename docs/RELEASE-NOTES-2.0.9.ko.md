# HongMix 2.0.9

## 새 기능
- **AI 배경 제거** (입력 ⚙ › Key): 그린스크린 없이 사람만 남깁니다. 배경은 투명·흐리게·이미지 중에서 고르고, 품질은 빠름(기본, 1080p 프레임당 약 10ms)·균형·정밀 중에서 고릅니다. 맥 안에서 처리하며 방송 화면 처리를 기다리게 하지 않습니다.
- **리플레이 클립 내보내기** (리플레이 클립 줄 ⬇, ⌘로 여러 개): 가로 16:9·세로 9:16·정사각 1:1(자를 위치 지정), 클립 앵글 또는 앵글마다 따로, 원래 속도·50% 슬로·AI 슬로, 앞뒤 여유 0~2초, H.264·HEVC·ProRes. 뒤에서 진행되어 방송과 리플레이 재생을 멈추지 않습니다.
- **새 자막 엔진** (macOS 26 이상): 방송 내내 한 번에 계속 듣는 장시간용 음성 인식 엔진입니다. 1분마다 끊었다 다시 시작하지 않아 문장이 잘리지 않습니다. 맥 안에서 처리하고 약 1초 안에 단어 단위로 표시되며, SRT에는 실제로 말한 시간이 기록됩니다. 이보다 오래된 macOS에서는 기존 엔진을 씁니다.
- **자막 모양** (Tools › Captions): 오른쪽형·하단 영화형·하단 띠·직접 지정. 줄 수, 한 줄 글자 수, 글자 크기, 자간, 줄 간격, 줄 사이 여백, 글자 가로 비율, 위치와 크기, 정렬, 배경(줄마다·상자·띠·없음)과 진하기, 글자 색, 외곽선, 폰트를 바꿀 수 있습니다. 'AI 자막' 표시는 끄거나, 문구·크기·위치(자막 바로 위·영역 왼쪽 위·직접 지정)를 바꿀 수 있습니다. 줄은 위로 밀려 올라가고, 말하는 중인 문장은 하늘색으로 미리 보입니다. 영상 크기는 바꾸지 않습니다.
- **읽는 속도**: 한 줄이 최소 1.5초(조정 가능)는 화면에 머물고, 밀린 줄이 많으면 자동으로 따라잡습니다.
- **용어집·교정**: 국정감사·예산 용어 440개를 음성 인식에 미리 알려 주고, "국정 감사 → 국정감사"처럼 정해 둔 단어만 고칩니다. 다른 파일로 바꿀 수 있습니다.
- '테스트 문장 보내기'·'자막 지우기' 버튼과 자막·배경 제거·리플레이 내보내기 API를 추가했습니다(Companion·MIDI용).

## 수정
- 오래 켜 두면 자막이 멈추던 문제를 고쳤습니다. 음성 인식 요청이 실패하면 즉시 무한히 다시 요청하는 바람에 맥의 음성 인식 서비스가 고장 나던 현상입니다. 이제 간격을 늘려 가며 다시 시도하고, 상태를 화면에 표시합니다.
- 다시 연결하는 동안 들어온 소리를 버리지 않습니다.
- 자막이 한 줄에 몰려 글자가 작아지던 문제를 고쳤습니다. 이제 줄을 나눠 표시합니다.
- 한국어 띄어쓰기가 바뀔 때 자막 줄이 뒤섞이거나 말하는 도중 지워지던 문제를 고쳤습니다.
- 같은 언어로 번역하도록 설정되어 있으면 번역을 끈 것으로 처리합니다. 번역에 실패하면 안내를 표시합니다.
- 미리보기 화면이 창이 있는 모니터를 따라가고, 화면 갱신 신호가 끊겨도 계속 그려집니다.
- 설정 화면의 숫자 입력칸을 모두 같은 모양으로 맞췄습니다. MIDI 학습·Virtual Set·리플레이 소스·타이틀 편집 화면에서 글자가 잘리던 곳과 빈 화면 안내도 정리했습니다.

## 검증 (M1 Max)
- **자막**: 25초 한국어 음성을 반복 재생해 비교했습니다.
  - 기존 엔진(2분): 문장이 통째로 빠졌습니다.
  - 새 엔진(3분 반): 8번 중 8번 모두 표시됐고, 단어 하나만 잘못 인식했습니다. 음성 인식 오류는 0건이었습니다.
- **AI 배경 제거**: 1080p59.94에서 빠름 10.4ms, 방송 화면 처리 1.0ms, 드롭 0.
- **리플레이 내보내기**: 가로·세로·정사각, 슬로, ProRes·HEVC 파일을 확인했습니다.

실제 회의(여러 명이 동시에 말하는 경우·잡음) 자막, 실제 카메라로 배경 제거, 두 번째 모니터는 아직 확인하지 못했습니다. 설정 창이 열린 상태에서는 종료가 되지 않으니 창을 먼저 닫아 주세요.
