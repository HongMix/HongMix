# HongMix 1.3.25 (Build 40)

- Folded inputs now move into a compact left-side list instead of occupying empty thumbnail tiles.
- The folded list shows each input number, name, and state. Select a row to load it into Preview, or use the arrow to expand its tile.
- Drag and drop reordering remains available from folded rows.
- Expanded inputs continue to use the available grid space.
