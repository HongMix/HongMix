# HongMix 2.3.1 (빌드 149)

HongMix 2.3.1은 입력을 실수로 닫지 않도록 확인 절차를 추가하고, 바로 소리가 나는 웹 페이지를 입력으로 추가할 때 드물게 앱이 종료되던 문제를 고쳤습니다. 예기치 않게 종료된 뒤에는 충돌 보고서를 쉽게 찾을 수 있습니다.

## 안전한 입력 닫기

- 입력 타일의 **×**나 타일 메뉴로 입력을 닫을 때 확인 창이 나타납니다.
- **다시 묻지 않기**를 선택할 수 있으며, **설정 › 일반 › 실수 방지**에서 다시 켤 수 있습니다.
- 위쪽의 **Undo**로 마지막에 닫은 입력을 계속 되살릴 수 있습니다.
- 자동화를 막지 않도록 API·Companion·Stream Deck의 입력 삭제 명령은 바로 실행됩니다.

## 웹 입력 안정성

- Suno 오버레이처럼 바로 소리가 나는 웹 페이지를 입력으로 추가할 때 드물게 앱이 종료되던 문제를 고쳤습니다.
- 내장 Chromium 브라우저가 완전히 닫힐 때까지 웹 입력을 유지하여, 늦게 도착한 화면·오디오·상태 콜백이 이미 해제된 입력에 접근하지 않게 했습니다.
- 생성이 끝나기 전에 닫기를 요청한 브라우저도 생성 직후 바로 닫힙니다.

## 충돌 보고서 안내

- HongMix 자체가 충돌했다면 다음 실행 때 저장된 충돌 보고서를 안내하고 Finder에서 바로 보여 줍니다.
- 같은 문제가 다시 생기면 해당 파일을 GitHub 이슈에 첨부해 주세요.

## 검증

- 실행 즉시 오디오를 재생하는 로컬 페이지를 120회 추가·삭제하는 테스트에서 충돌이 없었습니다.
- 번역 검사와 코어 테스트를 통과했고, DMG 무결성과 빌드 149 DMG·PKG의 체크섬을 확인했습니다.

## 알려진 제한

- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
