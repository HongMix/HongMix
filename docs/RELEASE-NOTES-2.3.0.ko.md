# HongMix 2.3.0 (빌드 143)

HongMix 2.3.0은 H.264 출력의 프레임레이트 인식 문제를 고친 버전입니다. 같은 수정이 먼저 미공개 2.2.9로 빌드됐지만, 2.2.9는 배포하지 않았습니다.

## H.264 프레임레이트 정보

- H.264 송출·SRT 출력·녹화 헤더에 프레임레이트 정보를 기록합니다.
- AJA BRIDGE LIVE 같은 수신 장비가 HongMix의 59.94fps 출력을 58.94로 잘못 인식하던 문제를 고쳤습니다.
- 영상 데이터와 타임스탬프는 바꾸지 않습니다. 헤더 정보를 기준으로 판정하는 수신 장비를 위해 H.264 시퀀스 헤더에 타이밍 정보만 추가합니다.

## 검증

- 사용자가 실제 AJA BRIDGE LIVE에서 같은 1080p59.94 출력이 59.94로 표시되는 것을 확인했습니다.
- 코어 테스트가 VideoToolbox 녹화 경로를 통과했고 H.264 헤더의 타이밍 정보를 확인했습니다.
- 빌드 143의 번역·체크섬·DMG 무결성·애드혹 앱 서명 검사를 통과했습니다.

## 알려진 제한

- 출력 메타데이터만 바뀌었으며 화면 변경과 새 캡처는 없습니다.
- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
