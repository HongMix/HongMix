# HongMix 2.1.7 (빌드 117)

## 정확한 위치·레이어 편집

- 위치·레이어의 모든 값에 숫자칸과 −/+를 넣었습니다. 화살표 키는 한 단계, Shift는 열 단계입니다.
- 회색 여백에서 화면 밖 상자와 손잡이를 계속 잡을 수 있고 벗어난 길이를 픽셀로 표시합니다.
- 화살표 키로 1px(Shift: 10px) 이동하며 Command-Z 또는 되돌리기 버튼으로 배치를 복구합니다.
- 레이어 불투명도·회전·잠금, 화면에 맞추기·가운데·원래 비율·전체 화면·위치 복사/붙여넣기를 추가했습니다.

## 자르기·투명 배경·호환성

- 레이어에서 잘라낸 소스가 상자를 맞추거나 채우도록 바꿔 vMix 사각형 작업 방식에 맞췄습니다.
- 이전 프로젝트는 열 때 자동 변환해 기존에 자른 레이아웃이 같은 모습으로 보입니다.
- 투명 배경만 잘라내기를 지원되는 알파 그래픽에서 수정했고, 투명 가장자리가 없는 소스는 이유를 화면 안에 표시합니다.

## AI 화질 올리기와 성능

- 지원되는 저해상도 송출 소스를 Apple VideoToolbox 실시간 모델로 확대합니다. 기본값은 꺼짐이며 macOS 26 이상이 필요합니다.
- 변하지 않은 레이어 합성을 재사용하고 바뀐 합성은 프레임당 GPU 대기 한 번으로 묶었습니다. 측정한 1080p29.97 레이어 다중 장면에서 평균 렌더 시간이 5.91ms에서 3.07ms로 줄었습니다.

## 안정성과 검증

- 유한하지 않은 API·입력값으로 인한 충돌/저장 실패, 송출에서 내린 입력의 업스케일 정지 화면, 업스케일 재시도·해상도 변경, 레이어 편집 경쟁 상태와 중첩 레이어 지연을 수정했습니다.
- 40분 자동 안정성 시험에서 프레임 빠짐 0, API 오류 0, 재시작 0, 메모리 302~365MB로 일정했습니다.
- 360p → 480p → 1080p → 360p 변경에서 드롭 0을 확인했습니다. 코어 테스트·번역·체크섬·DMG·애드혹 앱 서명 검증을 통과했습니다.

## 알려진 제한

- 실제 마우스 드래그, 화살표 이동, 숫자 버튼, 값 입력과 Command-Z는 더 많은 직접 조작 검증이 필요합니다.
- 되돌리기 기록은 현재 앱 실행 중에만 유지됩니다.
- 회전 레이어의 자르기 손잡이는 자르기 값만 바꾸고 상자 가장자리는 움직이지 않습니다.
- 공개 앱은 애드혹 서명이며 아직 Apple 공증 전입니다.
